# FuncFund

**Сервис агрегации и аналитики личного инвестиционного портфеля** для DIY-инвесторов с несколькими брокерами и банками (фокус — MOEX).

Один дашборд вместо Excel и переключения между приложениями: импорт отчётов, ручной добор позиций, live-котировки и структура портфеля. Продукт **не** даёт инвестиционных рекомендаций, прогнозов и сигналов buy/sell/hold — только факты и контроль данных.

## Сценарий проверки

Воспроизводимый сценарий на живом демо (PWA / mobile web на https://funcfund.ru):

1. **Логин**  
   Открыть https://funcfund.ru → войти под `demo@funcfund.local` / `Demo-Cbr1W3748t6VqxVm5vR7`.

2. **Дашборд**  
   Убедиться, что открывается единый портфель: позиции и оценка; котировки обновляются по WebSocket (живой снапшот, без ручного refresh).

3. **Позиции / импорт**  
   - Просмотреть уже загруженные позиции демо-портфеля.  
   - При необходимости: ручное добавление актива через поиск dictionary/MOEX **или** импорт брокерского отчёта (Сбер HTML) / статус интеграции Т-Инвестиций.

4. **Billing**  
   Перейти к тарифам / Premium checkout (ЮKassa). Проверить, что планы приходят с бэка и открывается сценарий оплаты (для оценки достаточно дойти до checkout; реальный платёж не обязателен).

Ожидаемый итог: auth работает, дашборд показывает агрегированный портфель с live-котировками, есть путь к импорту/добору позиций и к Premium checkout.

В этом репозитории для сверки API см. `contracts/public/`; UI-контракт legacy web — `frontend/`. Полный runnable backend в public mirror не включён — проверка сценария идёт через демо выше.

## Ключевые результаты спринта

За этап доведён mobile MVP (Expo/PWA):

- регистрация и auth
- единый дашборд с WebSocket-котировками
- импорт Сбер (HTML)
- подключение Т-Инвестиций (синхронизация лотов)
- ручное добавление активов через dictionary/MOEX
- история портфеля (ClickHouse)
- Premium checkout через ЮKassa

Оформлены legal (самозанятость/ИП, оферта, Политика ПД). Проведены **14 CustDev-интервью** (боль мультисчетов, важность автоагрегации **9.1/10**); демо показано научному руководителю; согласована тема/направление развития (тема 2).
