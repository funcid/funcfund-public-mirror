# FuncFund (public mirror)

**Агрегация и аналитика личного инвестиционного портфеля** для DIY-инвесторов с несколькими брокерами и банками.

Один дашборд вместо ручной сверки Excel и переключения между приложениями. Сервис показывает структуру, динамику и риск-метрики — **не** выдаёт инвестиционные рекомендации.

## Демо

- Продукт: [https://funcfund.ru](https://funcfund.ru)

## Что в этом репозитории

Публичный mirror для акселераторов и внешних ревьюеров. Здесь только то, что можно открыто показывать:

| Путь | Содержание |
|---|---|
| `frontend/` | Legacy web-клиент (React + Vite) |
| `contracts/public/` | Внешние OpenAPI-контракты (без internal/webhooks) |
| `docs/architecture.md` | Высокоуровневая схема |

## Чего здесь нет

Исходники бэкенда, мобильного клиента, парсеров брокеров, деплоя, секретов и внутренней аналитики **не публикуются**. Основной код остаётся в приватном репозитории.

## Стек (кратко)

- Клиенты: Expo / PWA (primary), React + Vite (legacy web)
- API: Kotlin, Spring Boot, WebFlux
- Данные: PostgreSQL, Redis, OpenSearch, ClickHouse
